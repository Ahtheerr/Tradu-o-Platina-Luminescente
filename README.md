## 📂 Como instalar

### Nintendo Switch (LayeredFS)

1. Baixe o arquivo `Switch.zip` na página de Releases.
2. Extraia o conteúdo do arquivo.
3. Copie os arquivos da tradução para a estrutura do **LayeredFS** utilizada pelo Luminescent Platinum, mesclando as pastas correspondentes e substituindo os arquivos quando necessário.
4. Inicie o jogo com o mod e a tradução instalados.

**Importante:** a tradução deve ser aplicada junto ao **Luminescent Platinum**, não como substituição do mod.

### Recomp

1. **Confira o aviso de compatibilidade no início desta página.**
2. Baixe o arquivo `Recomp.zip` na página de Releases.
3. Extraia o conteúdo e coloque os arquivos **na pasta do Recomp**, mantendo a estrutura de pastas e substituindo os arquivos correspondentes, se necessário.
4. Inicie o jogo normalmente.
